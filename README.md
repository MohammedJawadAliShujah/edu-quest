**Edu-Quest** is a web-based educational platform designed to transform the traditional learning experience into an engaging, gamified adventure. By integrating mission-based progression, competitive leaderboards, and interactive quizzes, Edu-Quest motivates students to stay consistent, improve their skills, and achieve their academic goals.

## 💡 Problem Statement
Traditional online learning platforms often suffer from high drop-off rates due to monotony and a lack of active engagement. Students often feel overwhelmed by static content and lack the motivation to track their progress effectively. Edu-Quest addresses this by turning education into a "quest," making learning as addictive and rewarding as a game.

## 🚀 Key Features
* **Mission-Based Learning:** Complete daily missions and courses to progress through the curriculum.
* **Gamification Elements:** Earn badges and rewards for every milestone achieved, providing instant feedback and gratification.
* **Interactive Quizzes:** Test your knowledge with built-in quiz modules designed to reinforce learning concepts.
* **Competitive Leaderboards:** Climb the ranks by tracking your performance against peers, fostering a healthy, competitive learning environment.
* **Personalized Dashboard:** A central hub to track your active courses, current streaks, and overall progress.
* **Dynamic UI:** Engaging interface featuring particle effects and responsive design to ensure a seamless experience across devices.

## 🛠 Tech Stack
Edu-Quest is built with a focus on speed, responsiveness, and interactivity:

* **Frontend:** HTML5, CSS3 (with custom animations and components), and Vanilla JavaScript.
* **Backend & Utilities:** Python (integrated for automation and script management) Fire base for backend and authentication.
* **Interactivity:** Custom particle effects via `particles.js` for an immersive user experience.

## ⚙️ Installation & Usage

### Prerequisites
* A modern web browser.
* (Optional) A local server environment (like VS Code Live Server) to view the project.

### Steps to Run
1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/MohammedJawadAliShujah/edu-quest.git](https://github.com/MohammedJawadAliShujah/edu-quest.git)
    ```
2.  **Navigate to the project folder:**
    ```bash
    cd edu-quest
    ```
3.  **Run the project:**
    * Python -m http.server 8000 to start the server,
    * Open `index.html` directly in your browser, or
    * Use the "Live Server" extension in VS Code to run it with hot-reloading.
